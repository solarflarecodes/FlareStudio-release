# FlareStudio

A fast, light screen recorder for Windows by **SolarFlareCodes**.

Capture and encoding run on the graphics card, so FlareStudio barely touches your processor, even while gaming. Recordings are crash-safe: if the app, the driver or the power fails, everything recorded so far is kept.

## Download

Get the latest **FlareStudio Setup** from [Releases](https://github.com/solarflarecodes/FlareStudio-release/releases/latest) and run it.

- Windows 10 (version 2004) or newer, 64-bit
- A GPU video encoder (NVIDIA, AMD or Intel) is recommended

## Updates

FlareStudio checks this page by itself and offers new versions in the app. Every update is signed by SolarFlareCodes and is verified before it installs; it never installs during a recording.

## Features

- Record a display, a window or a game, up to 4K and 240 fps, in H.264, HEVC or AV1
- Crash-safe recordings in every format
- PC sound, microphone and up to 16 apps, each on its own track
- Instant replay of the display and up to 3 pinned apps, at maximum quality
- Screenshots, global hotkeys, tray mode, dark and light themes
